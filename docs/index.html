Volatility 3 memory analysis reference

A Volatility 3 plugin reference for memory forensics, verified against a real install.

This is a Volatility 3 plugin reference built from a working memory-forensics workflow: 96 Windows plugins and 59 Linux plugins, mapped to the analysis phase each one belongs to, with the flags and an example command for each.

Verified against Volatility 3 stable v2.28 (2026-08-28). Every plugin name and flag in this reference was checked by running vol.py <plugin> -h against that release. Plugin sets change between versions -- check your own vol -h output if something here does not match what you have installed.

Get Volatility 3 running

pip install volatility3
vol -f memory.raw windows.info

See usage notes & legend for symbol tables, output formats, and the rest of the flags that apply across every plugin.

Framework & cross-OS plugins

10 plugins that work against any image type, regardless of OS.

PluginApplies toDescriptionCommand
banners.Banners All Scans the image for kernel banner strings. Identifies Linux kernels and confirms Windows images when info plugins fail.
vol -f mem.raw banners.Banners
isfinfo.IsfInfo All Reports available ISF symbol files and which images they match. First stop for symbol resolution failures.
vol isfinfo.IsfInfo
yarascan.YaraScan All YARA scanning across the full memory image, independent of OS and process context.
vol -f mem.raw yarascan.YaraScan --yara-file rules.yar
regexscan.RegExScan All Regex scanning across the full image — useful for flags, URLs, emails, and key material.
vol -f mem.raw regexscan.RegExScan --pattern "flag\{.*\}"
timeliner.Timeliner All Aggregates timestamps from all timestamp-producing plugins into one sortable timeline.
vol -f mem.raw -r csv timeliner.Timeliner > timeline.csv
layerwriter.LayerWriter All Writes the primary memory layer to a flat raw file — format conversion for third-party tools.
vol -f memory.dmp -o ./out layerwriter.LayerWriter
configwriter.ConfigWriter All Exports the resolved analysis configuration (layers, symbols, offsets) as JSON for reproducibility.
vol -f mem.raw -o ./out configwriter.ConfigWriter
frameworkinfo.FrameworkInfo All Lists the framework's own components: layers, symbol tables, automagic modules, and available plugins.
vol frameworkinfo.FrameworkInfo
volshell.py All Not a plugin — a second entry point shipped beside vol.py. Drops you into a Python shell with the image loaded so you can walk structures directly (ps(), dt('_EPROCESS'), db(addr)). This is how you answer questions no plugin covers.
python3 volshell.py -f mem.raw -w
vmscan.Vmscan All Scans for virtual machine host/guest structures inside a hypervisor memory image (nested memory analysis).
vol -f host.raw vmscan.Vmscan

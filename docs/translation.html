Volatility 2 to 3 translation

What each Volatility 2 command became in Volatility 3, and what has no replacement. 70 commands across 7 areas, for reading older writeups.

(no equivalent) marks a Volatility 2 command with nothing in Volatility 3 -- 11 of 70. Everything else has a direct or near-direct replacement.

Image Identification

Volatility 2Volatility 3Notes & differences
imageinfowindows.infoVolatility 3 has no profiles. windows.info reads the build from symbols instead of guessing, so there is nothing to pass to a --profile flag.
kdbgscan(no equivalent)KDBG guessing existed to fix profile mismatches. Symbol-driven analysis removes the problem; if windows.info works, the kernel was resolved correctly.
kpcrscanwindows.kpcrsSame data, no scanning needed — the KPCR is located through symbols.
crashinfowindows.crashinfoDirect equivalent.
hibinfo(no equivalent)Hibernation files are handled automatically by the layer stackers; there is no separate info plugin.
imagecopy / raw2dmplayerwriter.LayerWriterWrites the resolved layer out as flat raw. Format conversion is now generic rather than per-format.
vboxinfo / vmwareinfo / hpakinfo(no equivalent)VirtualBox, VMware and HPAK containers are auto-detected and stacked; you no longer inspect or convert them manually.

Processes, DLLs & Threads

Volatility 2Volatility 3Notes & differences
pslistwindows.pslistDirect equivalent. Use --physical for physical offsets (was -P).
pstreewindows.pstreeDirect equivalent.
psscanwindows.psscanDirect equivalent.
psdispscan(no equivalent)DISPATCHER_HEADER scanning was XP-x86 only and unmaintained even in Volatility 2.
psxviewwindows.malware.psxviewMoved into the .malware namespace along with the rest of the detection plugins.
dlllistwindows.dlllistDirect equivalent. --pid replaces -p.
dlldumpwindows.dlllist --dumpNo separate dump plugin — dumping is now a flag on the listing plugin. Requires the global -o output directory.
ldrmoduleswindows.malware.ldrmodulesSame PEB-vs-VAD cross-view, new namespace.
handleswindows.handlesDirect equivalent.
getsidswindows.getsidsDirect equivalent.
privswindows.privilegesRenamed. Class is Privs, module is privileges.
envarswindows.envarsDirect equivalent.
verinfowindows.verinfoDirect equivalent.
enumfuncwindows.iat / windows.pe_symbolsPartial. IAT parsing and symbol resolution are split across two plugins; there is no single import/export enumerator.
threadswindows.threadsDirect equivalent.
thrdscanwindows.thrdscanDirect equivalent.
cmdscanwindows.cmdscanDirect equivalent.
consoleswindows.consolesDirect equivalent — still the plugin that returns attacker input and output together.

Process Memory

Volatility 2Volatility 3Notes & differences
memmapwindows.memmapDirect equivalent.
memdumpwindows.memmap --dumpFolded into memmap as a flag.
procdumpwindows.pslist --dumpFolded into pslist. For a PE at an arbitrary address use windows.pedump --base instead.
vadinfowindows.vadinfoDirect equivalent. Still reports the ORIGINAL protection, not the current one.
vadwalkwindows.vadwalkDirect equivalent.
vadtreewindows.vadwalkNo dedicated tree view and no Graphviz/dot output in Volatility 3.
vaddumpwindows.vadinfo --dumpFolded into vadinfo. --maxsize caps oversized regions.
malfindwindows.malware.malfindNew namespace, and --dump now extracts the injected regions directly.
evtlogs(no equivalent)Parsed XP/2003 binary .evt logs only. For modern .evtx, carve the files with filescan plus dumpfiles and parse them externally.
iehistory(no equivalent)No browser-history plugin in Volatility 3. Use regex or YARA scanning over process memory instead.

Kernel, Drivers & Objects

Volatility 2Volatility 3Notes & differences
moduleswindows.modulesDirect equivalent.
modscanwindows.modscanDirect equivalent.
moddumpwindows.modules --dumpFolded into modules; --base extracts a single driver.
ssdtwindows.ssdtDirect equivalent.
driverscanwindows.driverscanDirect equivalent.
driverirpwindows.driverirpDirect equivalent.

apihooks(no equivalent)No general IAT/inline hook scanner. The nearest coverage is windows.malware.unhooked_system_calls plus the direct/indirect syscall plugins.
impscan(no equivalent)No import rebuilding. Dump with pedump and rebuild the IAT in an external tool.

Networking

Volatility 2Volatility 3Notes & differences
connections / connscan / sockets / sockscanwindows.netscanThe four XP-era plugins collapsed into one scanner covering TCP and UDP, IPv4 and IPv6, on all supported builds.
netscanwindows.netscanDirect equivalent. windows.netstat is the list-walking counterpart.

Volatility 2Volatility 3Notes & differences
hivelistwindows.registry.hivelistDirect equivalent.
hivescanwindows.registry.hivescanDirect equivalent.
printkeywindows.registry.printkeyDirect equivalent. --key takes the path, --offset scopes it to one hive.
hivedumpwindows.registry.printkey --recurseNo separate plugin — recursion is a flag.
hashdumpwindows.registry.hashdumpMoved under the registry namespace. Needs pycryptodome installed.
lsadumpwindows.registry.lsadumpMoved under the registry namespace.

userassistwindows.registry.userassistDirect equivalent.
shimcachewindows.shimcachememRenamed; reads the ahcache.sys AVL tree rather than the registry hive.
getservicesidswindows.getservicesidsDirect equivalent.
dumpregistry(no equivalent)To recover a hive file, locate it with windows.filescan and extract it with windows.dumpfiles.
shellbags(no equivalent)Notable gap. Shellbag parsing has no Volatility 3 plugin — dump NTUSER.DAT / USRCLASS.DAT and parse offline.
svcscanwindows.svcscanDirect equivalent, plus windows.svclist and windows.malware.svcdiff for cross-view.

File System & Misc

Volatility 2Volatility 3Notes & differences
mbrparserwindows.mbrscanRenamed.
mftparserwindows.mftscan.MFTScanRenamed. windows.mftscan.ADS and .ResidentData cover the other two views.
stringswindows.stringsDirect equivalent. Still needs a strings-tool output file passed via --strings-file.
timelinertimeliner.TimelinerNow OS-independent and lives at the top level, not under windows.
volshellvolshell.py (separate entry point)Shipped as its own script alongside vol.py, not as a plugin. See the Usage Notes sheet.
bioskbd / patcher / pagecheck(no equivalent)Niche Volatility 2 plugins with no Volatility 3 port.
linux_* / mac_*linux.* / mac.*The underscore naming was replaced by dotted namespaces, and Linux profiles were replaced by ISF symbol files built with dwarf2json.

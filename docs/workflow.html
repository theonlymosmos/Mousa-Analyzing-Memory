Analysis workflow

The recommended execution sequence for Windows and Linux memory images, phase by phase.

Windows workflow

10 phases
PhaseStageAssociated pluginsKey objectives
Phase 11. Image Identification & Triagewindows.info, banners.Banners, isfinfo.IsfInfo, windows.crashinfo, windows.kpcrs, windows.virtmapConfirm the image is parseable, identify OS build and architecture, and verify the correct symbol table loaded before anything else is trusted.
Phase 22. Processes & Threadswindows.pslist, windows.psscan, windows.pstree, windows.malware.psxview, windows.cmdline, windows.envars, windows.sessions, windows.getsids, windows.privileges, windows.getservicesids, windows.joblinks, windows.handles, windows.threads, windows.thrdscan, windows.suspended_threads, windows.malware.suspicious_threads, windows.dlllist, windows.malware.ldrmodules, windows.iat, windows.verinfo, windows.pe_symbols, windows.vadinfo, windows.vadwalkEstablish the process baseline, then attack it from multiple angles: hidden/unlinked processes, spoofed lineage, injected threads, unlinked DLLs, and RWX memory regions.
Phase 33. Network Connectionswindows.netscan, windows.netstatRecover active, closed, and listening endpoints; map outbound C2 (Command & Control) IP addresses and listening backdoors back to a specific PID and process image.
Phase 44. Registry Analysiswindows.registry.hivelist, windows.registry.hivescan, windows.registry.printkey, windows.registry.printkey --recurse, windows.registry.userassist, windows.registry.amcache, windows.shimcachemem, windows.registry.getcellroutineRead persistence keys (Run, Services, Winlogon, IFEO), recover execution evidence from AmCache/Shimcache/UserAssist, and detect registry-level rootkit hooks.
Phase 55. File & Disk Artifactswindows.filescan, windows.dumpfiles, windows.mftscan.MFTScan, windows.mftscan.ADS, windows.mftscan.ResidentData, windows.mbrscan, windows.symlinkscan, windows.memmap, windows.pslist --dump, windows.dlllist --dump, windows.vadinfo --dump, windows.modules --dump, windows.malware.malfind --dump, windows.truecryptLocate and extract files still resident in memory, recover MFT records and ADS for timeline building, and dump process address spaces for offline analysis.
Phase 66. Malware & Code Injectionwindows.malware.malfind, yarascan.YaraScan, windows.vadyarascan, windows.vadregexscan, windows.malware.hollowprocesses, windows.malware.processghosting, windows.malware.pebmasquerade, windows.malware.unhooked_system_calls, windows.malware.direct_system_calls, windows.malware.indirect_system_calls, windows.etwpatch, windows.debugregisters, windows.pedumpHunt injected and unbacked code, hollowed and ghosted processes, spoofed PEBs, EDR evasion via syscalls and ETW patching, and signature matches via YARA.
Phase 77. Kernel, Drivers & Rootkitswindows.modules, windows.modscan, windows.unloadedmodules, windows.driverscan, windows.malware.drivermodule, windows.driverirp, windows.devicetree, windows.ssdt, windows.callbacks, windows.timers, windows.orphan_kernel_threads, windows.bigpools, windows.poolscanner, windows.mutantscanDetect kernel-mode compromise: hidden drivers and modules, SSDT/IRP hooks, malicious callbacks and timers, and code executing from unbacked kernel memory.
Phase 88. Credentials & Secretswindows.registry.hashdump, windows.registry.lsadump, windows.registry.cachedump, windows.malware.skeleton_key_checkExtract NTLM hashes, LSA secrets, and cached domain credentials, and check for domain-level backdoors such as Skeleton Key.
Phase 99. Services, Tasks & Persistencewindows.svcscan, windows.svclist, windows.malware.svcdiff, windows.registry.scheduled_tasksAudit services and scheduled tasks for abnormal binary paths, hidden entries visible only to scanning, and attacker-created autostart mechanisms.
Phase 1010. User Activity, GUI & Extractionwindows.cmdscan, windows.consoles, windows.windowstations, windows.desktops, windows.windows.Windows, windows.strings, timeliner.Timeliner, layerwriter.LayerWriterRecover typed commands and console output, reconstruct on-screen activity, attribute raw strings to processes, and build a unified timeline of the incident.

Linux workflow

9 phases
PhaseStageAssociated pluginsKey objectives
Phase 11. Image Identification & Symbolsbanners.Banners, isfinfo.IsfInfo, linux.boottime, linux.vmcoreinfo, linux.kallsyms, linux.iomemIdentify the exact kernel build from the banner and confirm a matching ISF symbol file is loading — on Linux, no symbols means no analysis at all.
Phase 22. Processes & Threadslinux.pslist, linux.psscan, linux.pidhashtable, linux.pstree, linux.psaux, linux.envars, linux.capabilities, linux.malware.process_spoofing, linux.kthreads, linux.ptrace, linux.pscallstack, linux.proc.Maps, linux.elfs, linux.library_listBuild the task baseline from three independent enumeration paths, then check argv, environment, capabilities, name spoofing, and mapped ELFs for anomalies.
Phase 33. Network Connectionslinux.sockstat, linux.sockscan, linux.ip.Addr, linux.ip.Link, linux.malware.netfilterEnumerate sockets per task and by scanning, review interface state for sniffing, and inspect netfilter hooks used to hide or redirect traffic.
Phase 44. Rootkit & Hooking Detectionlinux.malware.check_syscall, linux.malware.check_idt, linux.malware.check_afinfo, linux.malware.check_modules, linux.malware.check_creds, linux.malware.tty_check, linux.malware.keyboard_notifiers, linux.tracing.ftrace, linux.tracing.tracepoints, linux.tracing.perf_events, linux.ebpfTest every classic and modern kernel hook point: syscall table, IDT, protocol handlers, credentials, TTY, notifiers, ftrace, tracepoints, perf, and eBPF.
Phase 55. Files & Filesystemlinux.lsof, linux.mountinfo, linux.pagecache.Files, linux.pagecache.InodePages, linux.pagecache.RecoverFsRecover open descriptors, mount and namespace layout for container context, and pull cached file content — up to the entire cached filesystem — out of RAM.
Phase 66. Malware, Modules & Injected Codelinux.malware.malfind, yarascan.YaraScan, linux.vmayarascan, linux.vmaregexscan, linux.lsmod, linux.malware.hidden_modules, linux.malware.modxview, linux.module_extractFind injected RWX regions, match YARA signatures inside process memory, and resolve module-level rootkits by cross-viewing lsmod against carved structures.
Phase 77. User Activity & Credentialslinux.bash, linux.kmsg, linux.graphics.fbdevRecover attacker-typed commands from in-memory bash history, read the kernel log for module loads and crashes, and recover console framebuffer content.
Phase 88. Evidence Extraction & Dumpinglinux.proc.Maps, linux.elfs, linux.module_extract, layerwriter.LayerWriterExtract the artifacts you found: specific VMAs, mapped and deleted ELF binaries, hidden kernel modules, and a flat raw copy of the memory layer.
Phase 99. Timelining & Framework Utilitiestimeliner.Timeliner, regexscan.RegExScan, configwriter.ConfigWriterAssemble a chronological account of the incident and preserve a reproducible configuration of how the image was parsed.

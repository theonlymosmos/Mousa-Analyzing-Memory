Linux plugins

All 59 Linux plugins from the workbook, grouped by the 9-phase analysis workflow, with a runnable example command for each.

1. Image Identification & Symbols 6 plugins

01
banners.Banners

Kernel Version Identification

Extracts kernel banner strings from the image (distro, kernel version, build date, compiler). Mandatory first step: the banner tells you exactly which ISF symbol file you must build or download.

vol -f mem.lime banners.Banners
02
isfinfo.IsfInfo

Symbol Table Inventory

Lists the ISF files Volatility can see and which banners they match. Use it to confirm your generated symbol file is actually being picked up.

vol isfinfo.IsfInfo
03
linux.boottime

System Boot Time

Reports when the system was started — anchors every other timestamp and lets you compute uptime at capture.

vol -f mem.lime linux.boottime
04
linux.vmcoreinfo

VMCoreInfo Table Parsing

Enumerates VMCOREINFO tables embedded in the image: kernel offsets, KASLR base, and structure sizes. Useful when symbols only partially resolve.

vol -f mem.lime linux.vmcoreinfo
05
linux.kallsyms

Kernel Symbol Enumeration

Enumerates kernel symbols from the in-memory kallsyms table, including symbols from loaded modules. Ground truth for validating addresses seen elsewhere.

vol -f mem.lime linux.kallsyms
06
linux.iomem

Physical Memory Map

Reproduces /proc/iomem — the physical address map of system RAM and device regions.

vol -f mem.lime linux.iomem

2. Processes & Threads 14 plugins

07
linux.pslist

Active Process Listing

Walks the task_struct linked list to enumerate running tasks (PID, TID, PPID, COMM, UID/GID, offset). Baseline process view.

vol -f mem.lime linux.pslist
08
linux.psscan

Hidden/Terminated Process Hunting

Scans memory for task_struct signatures independently of the linked list — reveals processes unlinked by a rootkit.

vol -f mem.lime linux.psscan
09
linux.pidhashtable

PID Hash Table Enumeration

Enumerates tasks through the kernel PID hash table — a third, independent view. Cross-compare with pslist and psscan for hidden tasks.

vol -f mem.lime linux.pidhashtable
10
linux.pstree

Process Lineage & Anomaly Detection

Renders the parent/child hierarchy. Catches shells spawned by web servers, cron-spawned implants, and reparented daemons.

vol -f mem.lime linux.pstree
11
linux.psaux

Execution Argument Auditing

Reconstructs full argv per task, like ps aux — exposes reverse-shell one-liners, curl-pipe-bash, and encoded payload arguments.

vol -f mem.lime linux.psaux
12
linux.envars

Process Environment Auditing

Dumps environment variables per process. LD_PRELOAD, HTTP_PROXY, and credentials passed via env show up here.

vol -f mem.lime linux.envars --pid 1234
13
linux.capabilities

Process Capability Auditing

Lists the capability sets of each task (permitted, effective, inheritable, bounding). CAP_SYS_ADMIN or CAP_SYS_MODULE on an odd process is a privilege-escalation lead.

vol -f mem.lime linux.capabilities
14
linux.malware.process_spoofing

Process Name Spoofing Detection

Compares each task's executable path against its cmdline and comm fields — catches implants masquerading as kernel threads or system daemons.

vol -f mem.lime linux.malware.process_spoofing
15
linux.kthreads

Kernel Thread Auditing

Enumerates kernel threads and their entry functions — a kthread whose function is not in a legitimate module is a kernel implant.

vol -f mem.lime linux.kthreads
16
linux.ptrace

Debugger Attachment Detection

Lists ptrace tracer/tracee relationships — reveals injection via ptrace and anti-debug self-tracing.

vol -f mem.lime linux.ptrace
17
linux.pscallstack

Task Call Stack Reconstruction

Reconstructs the kernel call stack of each task; frames resolving to unknown addresses indicate execution from hidden modules.

vol -f mem.lime linux.pscallstack
18
linux.proc.Maps

Process Memory Map Listing

Lists VMAs per process, like /proc/pid/maps: address range, permissions, and backing file. The Linux equivalent of vadinfo.

vol -f mem.lime linux.proc.Maps --pid 1234
19
linux.elfs

Mapped ELF Enumeration

Lists every memory-mapped ELF per process; --dump rebuilds them to disk for static analysis.

vol -f mem.lime -o ./out linux.elfs --pid 1234 --dump
20
linux.library_list

Shared Library Auditing

Lists shared objects loaded into each process — detects LD_PRELOAD hijacks and trojanised .so files.

vol -f mem.lime linux.library_list

3. Network Connections 5 plugins

21
linux.sockstat

Socket & Connection Listing

Enumerates sockets per task (TCP/UDP/UNIX/netlink) with local/remote addresses, state, and owning PID. Primary C2 and backdoor discovery plugin.

vol -f mem.lime linux.sockstat
22
linux.sockscan

Orphan Socket Scanning

Scans the memory layer for socket structures independent of the task list — finds sockets belonging to hidden or exited processes.

vol -f mem.lime linux.sockscan
23
linux.ip.Addr

Interface Address Listing

Lists network interfaces and their addresses, like ip addr show — including promiscuous-mode flags that suggest sniffing.

vol -f mem.lime linux.ip.Addr
24
linux.ip.Link

Interface Link-Layer Listing

Lists link-layer interface details, like ip link show — reveals unexpected tunnels, taps, and bridges.

vol -f mem.lime linux.ip.Link
25
linux.malware.netfilter

Netfilter Hook Inspection

Lists registered netfilter (iptables/nftables) hook functions; hooks owned by unknown modules are used for traffic hiding, redirection, or port-knocking triggers.

vol -f mem.lime linux.malware.netfilter

4. Rootkit & Hooking Detection 11 plugins

26
linux.malware.check_syscall

Syscall Table Hook Detection

Compares each syscall table entry against its expected symbol; anything pointing outside the kernel text is a hooked syscall.

vol -f mem.lime linux.malware.check_syscall
27
linux.malware.check_idt

Interrupt Table Tampering

Verifies the Interrupt Descriptor Table against known-good handlers — detects low-level interrupt hooking.

vol -f mem.lime linux.malware.check_idt
28
linux.malware.check_afinfo

Protocol Handler Hooking

Verifies af_inet/af_inet6 operation structures; hooked TCP/UDP handlers are used to hide connections from netstat-like tools.

vol -f mem.lime linux.malware.check_afinfo
29
linux.malware.check_modules

Module List Inconsistency Check

Compares the kernel module list against sysfs — a module in one and not the other has been unlinked to hide itself.

vol -f mem.lime linux.malware.check_modules
30
linux.malware.check_creds

Credential Structure Sharing

Detects processes sharing a cred structure — the fingerprint of a rootkit granting root to a chosen process.

vol -f mem.lime linux.malware.check_creds
31
linux.malware.tty_check

TTY Hook / Keylogger Detection

Checks tty receive_buf function pointers for hooks — the standard kernel keylogger technique.

vol -f mem.lime linux.malware.tty_check
32
linux.malware.keyboard_notifiers

Keyboard Notifier Chain Audit

Parses the keyboard notifier call chain; unexpected callbacks are keyloggers registered as notifiers.

vol -f mem.lime linux.malware.keyboard_notifiers
33
linux.tracing.ftrace

Ftrace Hook Detection

Detects function hooking implemented via the ftrace framework — the modern, stealthy successor to syscall table patching.

vol -f mem.lime linux.tracing.ftrace
34
linux.tracing.tracepoints

Tracepoint Hook Detection

Detects handlers attached to kernel tracepoints, another legitimate subsystem abused for stealth hooking.

vol -f mem.lime linux.tracing.tracepoints
35
linux.tracing.perf_events

Perf Event Abuse Detection

Lists perf events per process; attacker-registered events can capture data or execute callbacks without a module.

vol -f mem.lime linux.tracing.perf_events
36
linux.ebpf

eBPF Program Enumeration

Enumerates loaded eBPF programs and maps — increasingly the payload of choice for modern Linux rootkits and stealth C2.

vol -f mem.lime linux.ebpf

5. Files & Filesystem 5 plugins

37
linux.lsof

Open File Descriptor Listing

Lists open file descriptors per process (files, sockets, pipes, deleted files) with inode metadata — finds staged payloads and open exfil handles.

vol -f mem.lime linux.lsof
38
linux.mountinfo

Mounted Filesystem & Namespace Enumeration

Lists mount points per mount namespace — exposes container boundaries, bind mounts of host paths, and escape indicators.

vol -f mem.lime linux.mountinfo
39
linux.pagecache.Files

Page Cache File Listing

Lists files present in the kernel page cache, with paths and inode details — the Linux equivalent of filescan.

vol -f mem.lime linux.pagecache.Files
40
linux.pagecache.InodePages

Cached File Content Recovery

Lists and dumps the cached pages of a specific inode — recovers file content, including deleted files still cached in RAM.

vol -f mem.lime -o ./out linux.pagecache.InodePages --inode 0xffff9c0012345678 --dump
41
linux.pagecache.RecoverFs

Bulk Filesystem Recovery

Recovers the entire cached filesystem tree (files, directories, symlinks) into a compressed tarball. Heavy, but often yields the whole attacker toolkit.

vol -f mem.lime -o ./out linux.pagecache.RecoverFs

6. Malware, Modules & Injected Code 8 plugins

42
linux.malware.malfind

Code Injection Detection

Finds VMAs with write+execute permissions and no backing file — injected shellcode and unpacked payloads in process memory.

vol -f mem.lime linux.malware.malfind
43
yarascan.YaraScan

Full-Image Signature Hunting

Runs YARA rules across the whole image, kernel space included. Broadest sweep for known malware strings and flag patterns.

vol -f mem.lime yarascan.YaraScan --yara-string "flag{"
44
linux.vmayarascan

Process-Scoped YARA Hunting

Runs YARA against process VMAs so each hit maps to a PID and region — the actionable version of a raw-image hit.

vol -f mem.lime linux.vmayarascan --yara-file rules.yar
45
linux.vmaregexscan

Process-Scoped Regex Hunting

Regex search across process VMAs — URLs, IPs, key material, and CTF flag formats.

vol -f mem.lime linux.vmaregexscan --pattern "https?://[\\w./-]+"
46
linux.lsmod

Loaded Kernel Module Listing

Lists modules from the standard module list, with taint flags — the clean baseline for hidden-module comparison.

vol -f mem.lime linux.lsmod
47
linux.malware.hidden_modules

Hidden Module Carving

Carves module structures out of memory and reports those absent from the standard list — LKM rootkits that unlinked themselves.

vol -f mem.lime linux.malware.hidden_modules
48
linux.malware.modxview

Consolidated Module Cross-View

Merges lsmod, check_modules, and hidden_modules into one table with taint state — the fastest single command for module-level rootkit triage.

vol -f mem.lime linux.malware.modxview
49
linux.module_extract

Kernel Module Extraction

Rebuilds an ELF module from a kernel address to disk — how you recover a hidden LKM for reverse engineering.

vol -f mem.lime -o ./out linux.module_extract --base 0xffffffffc0123000

7. User Activity & Credentials 3 plugins

50
linux.bash

Bash History Recovery

Extracts in-memory bash history buffers with timestamps — direct evidence of the commands an attacker typed, including history never written to disk.

vol -f mem.lime linux.bash
51
linux.kmsg

Kernel Log Buffer Reading

Reads the kernel ring buffer (dmesg) — module loads, OOM kills, segfaults, and USB/device events around the incident.

vol -f mem.lime linux.kmsg
52
linux.graphics.fbdev

Framebuffer Extraction

Extracts framebuffer content from the fbdev subsystem — recovers what was rendered on the console screen.

vol -f mem.lime -o ./out linux.graphics.fbdev

8. Evidence Extraction & Dumping 4 plugins

53
linux.proc.Maps

Region-Level Memory Dumping

With --dump, writes selected VMAs to disk — the extraction step after malfind or a YARA hit identifies a region.

vol -f mem.lime -o ./out linux.proc.Maps --pid 1234 --dump
54
linux.elfs

Process Binary Recovery

With --dump, rebuilds mapped ELF images to disk, including deleted binaries still resident in memory.

vol -f mem.lime -o ./out linux.elfs --pid 1234 --dump
55
linux.module_extract

Hidden Module Extraction

Rebuilds a kernel module ELF from its base address — the extraction step after modxview or hidden_modules names an address.

vol -f mem.lime -o ./out linux.module_extract --base 0xffffffffc0123000
56
layerwriter.LayerWriter

Raw Layer Export

Writes the primary memory layer to a flat raw file — converts LiME, AVML, and crash formats for use with other tooling.

vol -f mem.lime -o ./out layerwriter.LayerWriter

9. Timelining & Framework Utilities 3 plugins

57
timeliner.Timeliner

Unified Forensic Timeline

Aggregates timestamps from every timestamp-producing Linux plugin into one chronological view — process starts, bash history, file metadata.

vol -f mem.lime timeliner.Timeliner
58
regexscan.RegExScan

Whole-Image Regex Search

Regex search across the entire image regardless of process context — the catch-all when a scoped scan finds nothing.

vol -f mem.lime regexscan.RegExScan --pattern "flag\\{.*\\}"
59
configwriter.ConfigWriter

Analysis Configuration Export

Writes the resolved configuration (layers, symbols, offsets) to JSON — makes a long analysis reproducible and shareable.

vol -f mem.lime -o ./out configwriter.ConfigWriter

Windows plugins

All 96 Windows plugins from the workbook, grouped by the 10-phase analysis workflow, with a runnable example command for each.

1. Image Identification & Triage 6 plugins

01
windows.info

OS & Architecture Verification

Displays OS build, architecture, kernel base, DTB and the symbol table that was resolved. Always the first command run — if this fails, no other plugin will work.

vol -f mem.raw windows.info
02
banners.Banners

Raw Banner String Hunting

Searches the raw image for kernel banner strings. Fallback when windows.info fails or the dump type is unknown (also used to identify Linux images).

vol -f mem.raw banners.Banners
03
isfinfo.IsfInfo

Symbol Table Inventory

Lists the ISF (Intermediate Symbol Format) files available to Volatility and which images they match. The go-to fix for 'symbol table not found' errors.

vol isfinfo.IsfInfo
04
windows.crashinfo

Crash Dump Header Parsing

Parses the header of a Windows crash dump (.dmp): build number, dump type, and physical memory run ranges.

vol -f memory.dmp windows.crashinfo
05
windows.kpcrs

Per-CPU Structure Listing

Prints the KPCR structure for each processor. Confirms CPU count and gives kernel structure entry points used by other plugins.

vol -f mem.raw windows.kpcrs
06
windows.virtmap

Kernel Virtual Layout Mapping

Lists virtual mapped sections of kernel space (paged pool, PFN database, session space) — context for interpreting kernel addresses.

vol -f mem.raw windows.virtmap

2. Processes & Threads 23 plugins

07
windows.pslist

Active Process Listing

Walks the EPROCESS doubly-linked list to enumerate running processes (PID, PPID, image name, create/exit time, offset). Baseline of every investigation.

vol -f mem.raw windows.pslist
08
windows.psscan

Hidden/Terminated Process Hunting

Pool-tag scans physical memory for EPROCESS objects independent of the linked list — surfaces terminated and DKOM-unlinked processes.

vol -f mem.raw windows.psscan
09
windows.pstree

Process Lineage & Anomaly Detection

Renders parent/child hierarchy. Key for spotting abnormal ancestry (e.g. WINWORD.EXE -> powershell.exe, or services spawned by a user process).

vol -f mem.raw windows.pstree
10
windows.malware.psxview

Cross-View Hidden Process Detection

Compares four independent process enumeration methods and flags any process missing from one of them — the classic anti-rootkit cross-view check.

vol -f mem.raw windows.malware.psxview
11
windows.cmdline

Execution Argument Auditing

Prints the command line of each process from the PEB. Reveals encoded PowerShell, LOLBin abuse, and dropped file paths.

vol -f mem.raw windows.cmdline
12
windows.envars

Process Environment Auditing

Dumps environment variables per process — exposes injected paths, proxy settings, temp staging directories, and sometimes credentials.

vol -f mem.raw windows.envars --pid 1234
13
windows.sessions

Logon Session Mapping

Maps processes to their logon session and user, extracted from environment data. Distinguishes console, RDP, and service sessions.

vol -f mem.raw windows.sessions
14
windows.getsids

Process Ownership & Token SIDs

Prints the SIDs owning each process — identifies privilege context and token-stealing (e.g. a user process running as SYSTEM).

vol -f mem.raw windows.getsids
15
windows.privileges

Token Privilege Auditing

Lists token privileges per process and whether each is enabled — flags SeDebugPrivilege or SeImpersonatePrivilege abuse.

vol -f mem.raw windows.privileges --pid 1234
16
windows.getservicesids

Service SID Resolution

Derives service SIDs and maps them to service names — links a token back to the service that owns it.

vol -f mem.raw windows.getservicesids
17
windows.joblinks

Job Object Membership

Prints job object links per process; useful for spotting sandboxed/containerised children and job-based process grouping.

vol -f mem.raw windows.joblinks
18
windows.handles

Open Handle Inspection

Lists open handles per process (files, keys, mutexes, processes, tokens). Reveals malware mutexes, opened victim processes, and staged file paths.

vol -f mem.raw windows.handles --pid 1234
19
windows.threads

Thread Enumeration & Context

Enumerates threads per process with start addresses — a start address outside any mapped module is a strong injection indicator.

vol -f mem.raw windows.threads
20
windows.thrdscan

Orphan Thread Scanning

Pool-scans for ETHREAD objects, including threads belonging to hidden or exited processes.

vol -f mem.raw windows.thrdscan
21
windows.suspended_threads

Suspended Thread Detection

Lists threads in a suspended state — typical of process hollowing and injection before the payload is resumed.

vol -f mem.raw windows.suspended_threads
22
windows.malware.suspicious_threads

Anomalous Thread Start Detection

Flags userland threads whose start address is unbacked, in a private region, or inconsistent with the owning module.

vol -f mem.raw windows.malware.suspicious_threads
23
windows.dlllist

Loaded Library Inspection

Lists DLLs loaded per process with their base addresses and full paths — reveals sideloaded, unsigned, or oddly-pathed modules.

vol -f mem.raw windows.dlllist --pid 1234
24
windows.malware.ldrmodules

PEB Unlinking Detection

Compares the three PEB module lists against the VAD tree; a module present in one but not the others indicates a manually mapped or unlinked DLL.

vol -f mem.raw windows.malware.ldrmodules --pid 1234
25
windows.iat

Import Address Table Auditing

Extracts the IAT of a process image to enumerate imported APIs, and to detect IAT hooking or suspicious API surface.

vol -f mem.raw windows.iat --pid 1234
26
windows.verinfo

PE Version Metadata

Reads version resources from mapped PE files — spot forged company/product strings on masqueraded binaries.

vol -f mem.raw windows.verinfo
27
windows.pe_symbols

PE Symbol Resolution

Resolves symbols inside PE files in process and kernel memory — used to attribute unnamed addresses to real functions.

vol -f mem.raw windows.pe_symbols
28
windows.vadinfo

Memory Region Enumeration

Lists every VAD (virtual address descriptor) with protection flags and backing file. PAGE_EXECUTE_READWRITE with no file is the injection signature.

vol -f mem.raw windows.vadinfo --pid 1234
29
windows.vadwalk

VAD Tree Traversal

Walks the raw VAD tree structure (parent/left/right nodes) — used to validate a tree that malfind or vadinfo could not parse cleanly.

vol -f mem.raw windows.vadwalk --pid 1234

3. Network Connections 2 plugins

30
windows.netscan

Network Artifact & C2 Hunting

Pool-scans for network objects: all active and closed connections for all processes, identifying foreign IPs, listening ports, owning PIDs, and timestamps. Works across all modern Windows builds.

vol -f mem.raw windows.netscan
31
windows.netstat

Live Structure Network Walk

Traverses the live network tracking structures instead of scanning. Fewer false positives than netscan, but misses closed connections.

vol -f mem.raw windows.netstat

4. Registry Analysis 8 plugins

32
windows.registry.hivelist

Active Hive Mapping

Lists loaded registry hives with virtual/physical offsets. Provides the --offset value other registry plugins need.

vol -f mem.raw windows.registry.hivelist
33
windows.registry.hivescan

Unlinked/Deleted Hive Hunting

Pool-scans for CMHIVE structures — finds hives unlinked from the list or belonging to unloaded user profiles.

vol -f mem.raw windows.registry.hivescan
34
windows.registry.printkey

Registry Key & Value Reading

Prints keys and values under a hive or path. The primary persistence check: Run, RunOnce, Services, Winlogon, IFEO.

vol -f mem.raw windows.registry.printkey --key "Microsoft\\Windows\\CurrentVersion\\Run"
35
windows.registry.printkey --recurse

Full Hive Dumping

Recursively walks every key and value under a hive or subkey — the Volatility 2 hivedump equivalent. Pipe to a file; output is large.

vol -f mem.raw windows.registry.printkey --offset 0xf8a000024010 --recurse
36
windows.registry.userassist

GUI Execution Evidence

Decodes UserAssist entries — programs launched from Explorer with run counts and last-execution timestamps.

vol -f mem.raw windows.registry.userassist
37
windows.registry.amcache

Application Execution History

Parses the AmCache hive: executed binaries, full paths, SHA-1 hashes, and first-run timestamps. Strong execution evidence.

vol -f mem.raw windows.registry.amcache
38
windows.shimcachemem

Shimcache Execution Artifacts

Reads Shimcache (AppCompatCache) entries from the ahcache.sys AVL tree in memory — file paths and timestamps of executed/present binaries.

vol -f mem.raw windows.shimcachemem
39
windows.registry.getcellroutine

Registry Hook Detection

Reports hives whose GetCellRoutine handler has been hooked — a rootkit technique to hide registry content from live tools.

vol -f mem.raw windows.registry.getcellroutine

5. File & Disk Artifacts 14 plugins

40
windows.filescan

In-Memory File Object Scanning

Pool-scans for FILE_OBJECT structures. Identifies deleted and hidden files, timestamps (created/modified/accessed), full paths, and physical memory offsets of files referenced in memory.

vol -f mem.raw windows.filescan
41
windows.dumpfiles

Cached File Extraction

Dumps cached file contents (DataSectionObject/ImageSectionObject) to disk. Use the offset from filescan, or --pid to grab a process's files.

vol -f mem.raw -o ./out windows.dumpfiles --virtaddr 0xe00000123456
42
windows.mftscan.MFTScan

MFT Record Recovery

Carves $MFT FILE records from memory: filenames, MACB timestamps, and resident attributes — timeline material without the disk image.

vol -f mem.raw windows.mftscan.MFTScan
43
windows.mftscan.ADS

Alternate Data Stream Hunting

Extracts Alternate Data Streams from carved MFT records — a classic hiding place for payloads and download markers.

vol -f mem.raw windows.mftscan.ADS
44
windows.mftscan.ResidentData

Resident File Content Recovery

Recovers the content of small files stored resident inside MFT records — often scripts, configs, and notes.

vol -f mem.raw windows.mftscan.ResidentData
45
windows.mbrscan

Master Boot Record Scanning

Scans for and parses MBR structures in memory — detects bootkits and wiper-style MBR overwrites.

vol -f mem.raw windows.mbrscan
46
windows.symlinkscan

Object Symlink Scanning

Scans for symbolic link objects in the object manager namespace — reveals device mappings and drive-letter abuse.

vol -f mem.raw windows.symlinkscan
47
windows.memmap

Address Space Mapping / Dumping

Prints the virtual-to-physical mapping of a process and, with --dump, writes the full process address space to disk.

vol -f mem.raw -o ./out windows.memmap --pid 1234 --dump
48
windows.pslist --dump

Process Executable Extraction

Rebuilds and writes each listed process image to disk — the Volatility 2 procdump equivalent. Scope with --pid or you will dump every process.

vol -f mem.raw -o ./out windows.pslist --pid 1234 --dump
49
windows.dlllist --dump

DLL Extraction

Writes listed DLLs to disk — the Volatility 2 dlldump equivalent. --name filters by regex; fails if the PE header page is not resident.

vol -f mem.raw -o ./out windows.dlllist --pid 1234 --dump
50
windows.vadinfo --dump

Memory Region Extraction

Writes selected VAD regions to disk — the Volatility 2 vaddump equivalent, and the fallback when header-based dumping fails. --maxsize caps huge regions.

vol -f mem.raw -o ./out windows.vadinfo --pid 1234 --dump
51
windows.modules --dump

Kernel Driver Extraction

Writes kernel drivers to disk — the Volatility 2 moddump equivalent. --base extracts a single driver by address.

vol -f mem.raw -o ./out windows.modules --base 0xfffff88003980000 --dump
52
windows.malware.malfind --dump

Injected Region Extraction

Extracts exactly the regions malfind flagged, one file per VAD — the fastest path from detection to a sample you can analyse.

vol -f mem.raw -o ./out windows.malware.malfind --pid 1234 --dump
53
windows.truecrypt

Encryption Passphrase Recovery

Searches for cached TrueCrypt passphrases and keys left in memory by the driver.

vol -f mem.raw windows.truecrypt

6. Malware & Code Injection 13 plugins

54
windows.malware.malfind

Code Injection Detection

Finds private, committed VADs marked executable with no backing file, and hexdumps/disassembles the head — shellcode and injected PE headers (MZ) show up here.

vol -f mem.raw windows.malware.malfind
55
yarascan.YaraScan

Full-Image Signature Hunting

Runs YARA rules across the entire memory image (kernel and user space). Broadest signature sweep; use for known-malware or flag-string hunting.

vol -f mem.raw yarascan.YaraScan --yara-string "flag{"
56
windows.vadyarascan

Process-Scoped YARA Hunting

Runs YARA only against process VADs, so every hit maps to a PID and region — far more actionable than a raw-image hit.

vol -f mem.raw windows.vadyarascan --yara-file rules.yar
57
windows.vadregexscan

Process-Scoped Regex Hunting

Regex search across process memory regions — good for URLs, base64 blobs, wallet addresses, and CTF flag patterns.

vol -f mem.raw windows.vadregexscan --pattern "https?://[\\w./-]+"
58
windows.malware.hollowprocesses

Process Hollowing Detection

Compares the on-disk PE backing a process against its in-memory image to detect hollowing/replacement of legitimate binaries.

vol -f mem.raw windows.malware.hollowprocesses
59
windows.malware.processghosting

Process Ghosting Detection

Flags processes whose backing FILE_OBJECT is deleted, null, or delete-on-close — the ghosting/doppelgänging family of techniques.

vol -f mem.raw windows.malware.processghosting
60
windows.malware.pebmasquerade

Process Name Spoofing Detection

Compares the image path in EPROCESS against the PEB — catches malware that rewrites its own PEB to impersonate a system binary.

vol -f mem.raw windows.malware.pebmasquerade
61
windows.malware.unhooked_system_calls

EDR Unhooking Detection

Detects ntdll.dll stubs that differ from the clean on-disk version — the signature of userland EDR unhooking.

vol -f mem.raw windows.malware.unhooked_system_calls
62
windows.malware.direct_system_calls

Direct Syscall Detection

Finds syscall stubs executed outside ntdll (Hell's Gate / SysWhispers style) used to bypass userland hooks.

vol -f mem.raw windows.malware.direct_system_calls
63
windows.malware.indirect_system_calls

Indirect Syscall Detection

Detects the indirect-syscall variant where the syscall instruction is borrowed from ntdll but reached from foreign code.

vol -f mem.raw windows.malware.indirect_system_calls
64
windows.etwpatch

ETW Tampering Detection

Identifies patched ETW functions (e.g. EtwEventWrite) used to blind telemetry before executing payloads.

vol -f mem.raw windows.etwpatch
65
windows.debugregisters

Hardware Breakpoint Detection

Inspects thread debug registers (DR0-DR7) — hardware breakpoints are used both by anti-analysis code and by hooking frameworks.

vol -f mem.raw windows.debugregisters
66
windows.pedump

PE Extraction From Memory

Rebuilds and dumps a PE file from a given base address in process or kernel space — how you recover the payload for static analysis.

vol -f mem.raw -o ./out windows.pedump --pid 1234 --base 0x400000

7. Kernel, Drivers & Rootkits 14 plugins

67
windows.modules

Kernel Module Listing

Walks PsLoadedModuleList to list loaded kernel drivers with base addresses and paths.

vol -f mem.raw windows.modules
68
windows.modscan

Unlinked Kernel Module Scanning

Pool-scans for kernel modules independent of the list — modules present here but absent from windows.modules are hidden.

vol -f mem.raw windows.modscan
69
windows.unloadedmodules

Unloaded Driver History

Lists recently unloaded drivers with unload timestamps — evidence of a rootkit that loaded, acted, and removed itself.

vol -f mem.raw windows.unloadedmodules
70
windows.driverscan

Driver Object Scanning

Pool-scans for DRIVER_OBJECT structures, including drivers unlinked from the standard list.

vol -f mem.raw windows.driverscan
71
windows.malware.drivermodule

Hidden Driver Correlation

Correlates driver objects with kernel modules to prove a driver is hidden — a driver object with no matching module is a rootkit indicator.

vol -f mem.raw windows.malware.drivermodule
72
windows.driverirp

IRP Handler Hook Detection

Lists the IRP dispatch table of each driver; handlers pointing outside the owning driver's range indicate IRP hooking.

vol -f mem.raw windows.driverirp
73
windows.devicetree

Device Stack Inspection

Renders drivers and their attached devices as a tree — reveals filter drivers inserted into the keyboard, disk, or network stack.

vol -f mem.raw windows.devicetree
74
windows.ssdt

Syscall Table Hook Detection

Dumps the System Service Descriptor Table and resolves each entry to its owning module; entries outside ntoskrnl/win32k are hooks.

vol -f mem.raw windows.ssdt
75
windows.callbacks

Kernel Callback Auditing

Lists kernel notification routines (process/thread/image load, registry callbacks) — both a rootkit persistence point and an EDR footprint.

vol -f mem.raw windows.callbacks
76
windows.timers

Kernel Timer & DPC Auditing

Prints kernel timers and their associated DPC routines with owning module — a stealth execution path for kernel implants.

vol -f mem.raw windows.timers
77
windows.orphan_kernel_threads

Orphan Kernel Thread Detection

Finds kernel threads whose start address maps to no loaded module — code running from unbacked kernel memory.

vol -f mem.raw windows.orphan_kernel_threads
78
windows.bigpools

Large Pool Allocation Review

Lists big page pool allocations with tags — oversized or oddly-tagged allocations often hold kernel payloads.

vol -f mem.raw windows.bigpools
79
windows.poolscanner

Generic Pool Tag Scanning

Framework-level pool scanner used by the other *scan plugins; can be pointed at arbitrary tags for custom hunting.

vol -f mem.raw windows.poolscanner
80
windows.mutantscan

Mutex/Mutant Enumeration

Scans for mutant (mutex) objects. Malware families use hardcoded mutex names as single-instance markers — excellent IOC pivot.

vol -f mem.raw windows.mutantscan

8. Credentials & Secrets 4 plugins

81
windows.registry.hashdump

NTLM Hash Extraction

Extracts local account NTLM hashes from the SAM and SYSTEM hives in memory — evidence of, or material for, credential attacks.

vol -f mem.raw windows.registry.hashdump
82
windows.registry.lsadump

LSA Secret Extraction

Decrypts LSA secrets from the SECURITY hive: service account passwords, cached machine secrets, DPAPI keys.

vol -f mem.raw windows.registry.lsadump
83
windows.registry.cachedump

Domain Cached Credentials

Dumps cached domain credential hashes (MSCache/DCC2) for users who logged in without a reachable DC.

vol -f mem.raw windows.registry.cachedump
84
windows.malware.skeleton_key_check

Domain Controller Backdoor Check

Checks lsass for the Skeleton Key patch, which lets an attacker authenticate as any domain user with a master password.

vol -f mem.raw windows.malware.skeleton_key_check

9. Services, Tasks & Persistence 4 plugins

85
windows.svcscan

Service Enumeration & Anomaly Detection

Scans service records: name, display name, type, state, and binary path. Identifies malicious or suspicious service configurations, modified service paths, unverified distributors, and anomalous network-triggering services; paths in temp or user directories are prime persistence findings.

vol -f mem.raw windows.svcscan
86
windows.svclist

List-Based Service Enumeration

Enumerates services by walking the service record list rather than scanning — the clean baseline for comparison.

vol -f mem.raw windows.svclist
87
windows.malware.svcdiff

Hidden Service Detection

Diffs list-walked services against scanned services; anything only visible to the scanner is a service hidden by a rootkit.

vol -f mem.raw windows.malware.svcdiff
88
windows.registry.scheduled_tasks

Scheduled Task Persistence

Decodes scheduled tasks from the registry: actions, triggers, principals, and hidden-flag state. Top-tier persistence artifact.

vol -f mem.raw windows.registry.scheduled_tasks

10. User Activity, GUI & Extraction 8 plugins

89
windows.cmdscan

Command History Recovery

Recovers the command history buffers of cmd.exe (COMMAND_HISTORY), including commands typed and then cleared.

vol -f mem.raw windows.cmdscan
90
windows.consoles

Console Screen Buffer Recovery

Recovers full console input and output buffers — you get the attacker's commands together with the output they saw.

vol -f mem.raw windows.consoles
91
windows.windowstations

Window Station Enumeration

Scans for top-level window stations — the GUI containers used for session isolation and desktop hiding.

vol -f mem.raw windows.windowstations
92
windows.desktops

Desktop Object Enumeration

Lists desktop instances per window station; malware creates hidden desktops to run GUI apps invisibly.

vol -f mem.raw windows.desktops
93
windows.windows.Windows

Window Enumeration

Enumerates windows belonging to desktop instances, including titles — recovers what was on screen and by which process.

vol -f mem.raw windows.windows.Windows
94
windows.strings

String-to-Process Attribution

Takes output from the strings utility and maps each offset back to the owning process and virtual address — turns a raw string hit into a lead.

strings -td mem.raw > s.txt; vol -f mem.raw windows.strings --strings-file s.txt
95
timeliner.Timeliner

Unified Forensic Timeline

Aggregates timestamps from every plugin that produces them into one chronological timeline. Best single command for 'what happened, in order'.

vol -f mem.raw timeliner.Timeliner
96
layerwriter.LayerWriter

Raw Layer Export

Writes the primary memory layer out to a flat raw file — converts crash dumps, VMware, and hibernation images into raw for other tools.

vol -f memory.dmp -o ./out layerwriter.LayerWriter
